# Информационно-удостоверяющий лист (УЛ)

Форма по [ГОСТ 2.051-2013](https://docs.cntd.ru/document/1200105496)
«ЕСКД. Электронные документы. Общие положения».

УЛ применяют, когда электронный документ (прошивка, PDF чертежа, дистрибутив, CAD)
передаётся **без ЭЦП**: контрольная сумма связывает содержимое файла с реквизитной
частью. Учётная копия УЛ подписывается разработчиком / выпускающим и при необходимости
скрепляется печатью организации.

Связанные алгоритмы хеширования: ГОСТ Р 34.11-2012 (СТРИБОГ), при совместимости —
ГОСТ Р 34.11-94, SHA-256 (и др., если указаны в УЛ). Расчёт и проверка — утилита
`gostsum` (см. [README](../README.md), РЭ `ГКТУ.441465.003` в проекте ОПУ).

## Поля формы (практика ОПУ / ГКТУ)

| Зона | Содержание |
|------|------------|
| Перв. примен. | Обозначение изделия / документа первого применения |
| Номер п/п | Порядковый номер записи в листе |
| Обозначение документа | Децимальный номер (напр. `ГКТУ.468332.031-03`) |
| Наименование | Изделие и вид документа («… Исполняемый код», «… PDF» и т.п.) |
| Версия | Версия / сборка |
| Номер последнего изменения | Изм. |
| Имя файла | Имя электронного экземпляра (`.bin`, `.pdf`, …) |
| Алгоритм расчета | `GOST 34.11-2012`, `GOST 34.11-94`, `SHA256`, … |
| Контрольная сумма | HEX без пробелов (как печатает `gostsum`) |
| Примечание | Совместимость, состав комплекта и пр. |
| Основная надпись | «Информационно-удостоверяющий лист», лит., лист/листов, разраб./пров./утв., даты, инв. № |

Обозначение самого УЛ обычно: `<децимальный номер> УЛ` (пример: `ГКТУ.468332.031-03 УЛ`).

## Как заполнить через gostsum

```sh
# одна прошивка
./gostsum -a gost   firmware.bin
./gostsum -a gost94 firmware.bin   # только если УЛ ещё ведёт 34.11-94
./gostsum -a sha256 firmware.bin

# комплект: прошивка + PDF чертежа в архиве КД
./gostsum -a gost firmware.bin drawing.pdf > ul-sums.txt
# перенести строки HEX *имя в графы «Алгоритм» / «Контрольная сумма» / имя файла
./gostsum -a gost -c ul-sums.txt
```

Имена алгоритмов в УЛ ОПУ: `GOST 34.11-94`, `GOST 34.11-2012`, `SHA256`
(соответствуют `-a gost94`, `-a gost` / `gost512` для 512-бит, `-a sha256`).

Шаблон полей: [ul-blank.csv](ul-blank.csv), печатная форма A4: [ul-blank.html](ul-blank.html).  
Пример заполнения (вымышленные данные): [ul-example.md](ul-example.md).

## Примечание о термине

В архивном контуре встречается «лист учёта электронных документов» (ЛУЭД).
В ЕСКД для контрольных сумм электронных копий КД используется именно **УЛ**
(информационно-удостоверяющий лист) по ГОСТ 2.051-2013.
